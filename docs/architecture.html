sqlinsight architecture

A deterministic pipeline: raw .sql files in, decision-support artifacts out. Click any stage to see what it does, the algorithm, and a worked example. Data flows strictly left to right; models.py is the shared vocabulary.

The running example

Every stage's "Worked example" tab traces this same query, so you can follow one piece of SQL through the whole pipeline.

WITH recent_orders AS (
    SELECT o.order_id, o.customer_id, o.amount
    FROM orders o
    WHERE o.created_at > '2026-01-01'
)
SELECT c.region, SUM(r.amount) AS revenue
FROM recent_orders r
JOIN customers c ON r.customer_id = c.customer_id
GROUP BY c.region;

Non-negotiable invariants (every stage obeys these)

DeterminismSame input, byte-identical output. Everything sorted; no randomized algorithms.
ResilienceOne malformed query never crashes the run. Errors are recorded; partial results kept.
No guessingColumns that cannot be confidently attributed are marked ambiguous, never invented.
Honest framingClusters are suggestions for a human, not finished dbt models.
Offline artifactsAll outputs work with no network (pyvis resources inlined).
