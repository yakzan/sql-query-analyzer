sqlinsight architecture

A deterministic pipeline: raw .sql files in, decision-support artifacts out. This reflects the implemented system after all 8 roadmap steps shipped (see ROADMAP.md). Click any stage for its algorithm, a worked example traced on real code, and what changed during the roadmap and why. Data flows strictly left to right; models.py is the shared vocabulary.

The running example

Every stage's "Worked example" tab traces this same query. All traces below were generated by running the actual code, not written by hand.

WITH recent_orders AS (
    SELECT o.order_id, o.customer_id, o.amount
    FROM orders o
    WHERE o.created_at > '2026-01-01'
)
SELECT c.region, SUM(r.amount) AS revenue
FROM recent_orders r
JOIN customers c ON r.customer_id = c.customer_id
GROUP BY c.region;

Verification layers

The roadmap's first and biggest lesson: guarantees that are not tested are wishes. Four layers now hold the pipeline in place (60 tests).

Golden snapshotstests/golden/ pins clusters.csv and repeated_logic.csv. Intended changes are refreshed deliberately with UPDATE_GOLDENS=1 and reviewed as diffs. Both signal-quality changes (steps 4, 5) arrived exactly this way.
Determinism, provenTwo full runs must be byte-identical: every CSV, both HTML files, sqlite compared via ordered dumps. Also asserted at scale on the synthetic corpus.
Scale gatetests/gen_corpus.py (seed 42) generates 80 files / 60 tables with planted truth: 6 exact dupes, 5 near-dupes, composite keys, wide queries, inserts. Asserts recall, runtime < 30s (measured < 1s), graph.html < 3MB, no community > 60% of joined tables. uv run pytest -m slow
Behavior testsGolden unit tests on small SQL snippets per feature: kinds, star expansion, join inference guards, composite collapse, near-dupe grouping, order independence.

CLI surface

uv run sqlinsight path/to/sql -o output \
    [--catalog schema.json]   # real warehouse schema; wins per table, enables SELECT * expansion
    [--resolution 1.0]        # community detection resolution; > 1.0 = more, smaller clusters
    [--graph-edges 200]       # cap graph.html to top-K join edges; full set stays in join_edges.csv

Non-negotiable invariants (every stage obeys these)

DeterminismSame input, byte-identical output. Everything sorted; fixed seeds; no randomized algorithms. Now proven by tests, not just intended.
ResilienceOne malformed query never crashes the run. Errors are recorded; partial results kept.
No guessingUncertain attribution is labeled (ambiguous, join_inferred), never silently upgraded.
Honest framingClusters are suggestions. Unconnected tables say so. Inferred edges are dashed.
Offline artifactsAll outputs work with no network (pyvis resources inlined).
